# Star Counter

A small, cozy clicker game about lying on a hill at night and counting the stars.

You start out alone with a telescope and a sky full of stars. Every click on the sky counts a star. Spend the stars you've counted on sharper eyes, invite a friend to count with you, and keep an eye out for shooting stars.

Made with Python and pygame.


## How to play

- **Click the sky** to count stars. You can also hold the mouse button down.
- Each star you count leaves a little sparkle behind, so your sky fills up as you go.
- **Buy upgrades** with the cards along the bottom.
- **Catch shooting stars.** Every so often one streaks across the sky. Click it before it disappears for a big bonus.
- Press **Esc** or close the window to quit.

## Getting started

### Play it (Windows)

1. Go to the [**Releases**](../../releases) section of this repository.
2. Download the latest `.exe` file.
3. Put it in a folder of its own (your save file will be created next to it), and double-click to play.

No Python or installation needed.

> Windows might show a "Windows protected your PC" warning, because the game isn't signed. Click **More info → Run anyway**.

### Run from source (optional)

If you'd rather run the Python code yourself, you'll need **Python 3.8 or newer**:

```
pip install pygame
python main.py
```

Keep `main.py` and `upgrades.py` in the same folder.
